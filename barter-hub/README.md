# 🔄 SWAPIC — India's #1 Barter, Rent & Trade Network | बदले में बदलो!

> A modern, mobile-responsive circular economy marketplace built specifically for the **Indian user base**. Exchange products (अदला-बदली), rent gear for weddings and shoots (किराया), or buy & sell with **Aadhaar verification** and **UPI Escrow Protection (PhonePe / GPay / Paytm)**.

---

## 🇮🇳 Tailored for Indian Users

### 1. 💰 Indian Rupee (₹ INR) & UPI Escrow
- Complete pricing in **₹ (INR)** across all listings, daily rentals, barter valuations, and cash sweeteners.
- **UPI Escrow Protection**: Funds for purchases and rental security deposits are held securely and released only after verified handover.

### 4. 🔄 Triple-Mode Commerce
- **Direct Barter (अदला-बदली)**: Swap your items directly with wishlist matching and **UPI Cash Sweeteners** to equalize value differences.
- **Rent Gear (किराये पर)**: Rent cameras, tools, riding gear, or bridal outfits with real-time day calculation and refundable UPI security deposits.
- **Direct Purchase (खरीदें / बेचें)**: Buy pre-loved items with 100% inspection guarantee.

### 5. 💬 Indian Negotiation Chat
- Live negotiation messenger with pinned **Deal Lock** card.
- Ready-made Indian negotiation prompts (*"Bhai, is this still available?"*, *"Can we meet at the Metro Station?"*, *"+₹1,000 UPI cash sweetener"*).

## 🚀 How to Run the Website

### Method 1: Instant Python Server (Recommended)
Open your terminal in this directory and run:
```powershell
python server.py
```
This starts the local server and automatically opens **`http://localhost:8000`** in your browser.

### Method 2: Direct Browser Launch
Simply double-click [`index.html`](file:///C:/Users/LOQ/.gemini/antigravity/scratch/barter-hub/index.html) to open in Chrome, Edge, Firefox, or Safari!
